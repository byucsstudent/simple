# Software Construction

**Discipline:** Software Engineering
**Problem type:** Architecting client server applications
**Difficulty:** 1 / 5
**Modes:** Practice
**Instability:** Off

## Learning Outcomes

Successfully architecting complete solutions for real world problems is the pinnacle of software engineering discipline. In this assessment you will respond to a scenario that requires you to frame, research, design, describe a plan of action, and finally provide factors for validating your architecture for a client server application.

Defining outcomes include:

1. Appropriate use of specific technologies including a CLI client, Java based Server using HTTP, and MySQL.
2. Adoption of modern software engineering principles and architectures
3. Resilience, stability, and performance
4. Concurrency
5. Sufficient automated testing
